# 项目 JavaScript / TypeScript 笔记

本目录只记录 **当前宿主项目** 的 JS / TS 相关事实与长期沉淀，不属于通用 moomfe-js-ts Skill。

## 什么时候写进这里

适合记录：

- 当前项目的 TS 版本、tsconfig 严格度、类型相关工具链约束；
- lint / formatter 的特殊规则（会影响代码形态的那些）；
- 实际可用的工具库与类型库，以及明确不可用的；
- 与通用 Skill 不同的明确例外；
- 经过确认、未来任务仍然值得参考的写法与踩坑。

## 不要记录什么

- 临时排查过程；
- 一次性任务细节；
- 可以从代码本身直接看出来、且没有额外价值的信息；
- 只适用于某一个模块的普通实现。

## 维护规则

- `notes/` 的内容可以随着项目演进修改。
- 普通开发任务不需要为了"保持文档完整"而主动补笔记。
- 发现通用规则与项目实际情况冲突时，先遵守项目事实，再考虑把项目特有情况记录在这里。
- **不要把这里的内容反向塞进 `SKILL.md` / `references/`，除非用户明确要求更新通用 Skill。**

## 迁移

把 moomfe-js-ts Skill 复制到其他项目时，默认不复制本目录。
