# 项目 Vue 笔记

本目录只记录 **当前宿主项目** 的 Vue 相关事实与长期沉淀，不属于通用 moomfe-vue Skill。

## 什么时候写进这里

适合记录：

- 当前项目的 Vue / Nuxt / UI 库版本与特殊配置；
- 实际可用的组合式工具库（vueuse、@mixte/use 等）与使用范围；
- 项目中已存在、应该优先复用的组件与 composable；
- 与通用 Skill 不同的明确例外；
- 经过确认、未来任务仍然值得参考的 Vue 约定与踩坑。

## 不要记录什么

- 临时排查过程；
- 一次性任务细节；
- 可以从代码本身直接看出来、且没有额外价值的信息；
- 只适用于某一个组件实例的普通实现。

## 维护规则

- `notes/` 的内容可以随着项目演进修改。
- 普通开发任务不需要为了“保持文档完整”而主动补笔记。
- 发现通用规则与项目实际情况冲突时，先遵守项目事实，再考虑把项目特有情况记录在这里。
- **不要把这里的内容反向塞进 `SKILL.md` / `references/`，除非用户明确要求更新通用 Skill。**

## 推荐结构

复杂项目可以自行拆分：

```text
notes/
├── README.md
├── project-conventions.md
├── component-inventory.md
└── known-issues.md
```

简单项目只需要一个 `notes.md` 也可以。

## 迁移

把 moomfe-vue Skill 复制到其他项目时，默认不复制本目录。
