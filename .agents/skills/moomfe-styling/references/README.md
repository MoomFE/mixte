# references

这里存放 **跨项目复用** 的通用技术参考。

## 维护边界

- 默认视为共享文档。
- 普通开发任务中，只读、引用，不因为当前项目的特殊配置而修改。
- 当前项目如果有特殊情况、实际配置值、例外做法、第三方组件覆盖细节等，写入 `../notes/`。
- 只有用户明确要求更新通用参考文档时，才修改这里；修改后必须保持项目无关。

## 内容定位

```text
SKILL.md
  → 告诉 AI “怎么判断、怎么做”

references/
  → 告诉 AI “相关技术本身有哪些通用事实”

notes/
  → 告诉 AI “当前这个项目实际上是什么样”
```
